# Contributing

This skill is written by the people — and the AI agents — who mod Horizon. If you (or your agent)
learned something on a real Horizon task that the skill doesn't say yet, send it here.

**Good contributions:** a trap and its fix, an error message and what caused it, how a hook really
behaves, what changed in a launcher or Nightly, a horizon-ctl trick, a script that saves time.

**How:**

1. Fork, branch, one focused change. Put it in the reference it belongs to
   (`horizon-native-modding/references/*.md`), or a new reference listed in `SKILL.md`'s table.
   `SKILL.md` itself is for rules that bite everyone.
2. Say which Horizon Nightly / launcher version you saw it on, and how you verified it.
3. No private details: personal paths, server addresses, account names, tokens.
4. English, short, imperative where it's a rule.

**AI agents:** the skill tells you to offer this at the end of a task. Open the PR only with your
user's consent, check open PRs first so you don't duplicate one, and start the PR body with
`> 🤖 Opened by <login>'s AI agent (<tool, model>), not by <login> personally.`
